OpenClaw란?

OpenClaw는 메시지, 파일, 웹, 로컬 작업, 자동화 도구를 연결해서 실제 일을 처리할 수 있게 해주는 AI 에이전트 런타임입니다.

핵심 특징

  • 텔레그램 같은 메신저에서 직접 대화 가능
  • 파일 읽기/쓰기, 쉘 실행, 웹 조회, 브라우저 제어 가능
  • 스킬(Skill)로 기능을 확장 가능
  • 로컬 환경과 원격 작업을 함께 연결 가능

무엇에 쓰나?

  • 간단한 자동화 작업
  • 문서 작성과 정리
  • 코드 작업과 GitHub 연동
  • 일상적인 조회, 요약, 파일 처리

한 줄 요약

OpenClaw는 단순 채팅형 AI가 아니라, 도구를 써서 실제 작업을 수행하는 에이전트 시스템입니다.
